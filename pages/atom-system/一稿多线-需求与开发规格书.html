一稿多线 · 需求与开发规格书

交付版 v1.0 · 供任意开发环境实现 · 配套文档：《产品设计方案》《技术方案》《Atom 规范 v1.2》· 2026 年 10 月
本文档自包含：不需要访问任何现有代码库即可据此实现完整系统。实现目标是——输入一份讲课主题与讲解思路，生成讲稿；讲稿经人确认后，自动生产多条同步标注线（结构、重点、概念、图谱、意图），最终装配成一个播放工作台：上面幻灯片随讲切换，中间讲稿逐句滚动，下面各线轨道随时间联动。

一、项目背景与一句话定义

教学、培训、汇报都需要「讲」。本产品把讲课的核心资产收敛为一份文稿（母线）：声音由文稿合成，字幕由文稿对齐，一切标注以「线」为单位叠加在文稿的时间轴上。传统做法里声、画、字幕的对齐靠剪辑；本产品里对齐是数据结构自带的——没有需要对帧的环节，就没有对不齐的可能。

一句话定义：文稿是母线，声音与一切标注都是它的派生线；播放时一个时钟驱动所有线联动。

二、术语表

术语定义
母线文稿及其分句锚点系统。唯一信息源头，任何线不得反向修改它
锚点带时间的文稿最小单元。四级：章、节、分句、字；分句为默认锚点粒度
线（L）叠加在母线上的一类标注，六要素定义（见第五章），独立落盘、独立开关
卡片概念线的呈现单元：概念卡、问答卡、示例卡、提醒卡四种
工作台播放页：上区画面、中区讲稿、下区多线轨道，单文件网页
台面确认页：人阅读产物、勾选验收、确认执行的地方
排时给锚点赋时间。三代：语速估算 → 逐句语音合成回写 → 字级强制对齐

三、功能需求总表

编号需求优先级
FR1录入主题、讲课对象、讲解思路，生成讲稿初稿（分段分章，含标记语法）高
FR2讲稿确认台面：逐节展示、可编辑；确认即冻结母线，此后改讲稿须全量重跑高
FR3母线解析：切章、节、分句，标记校验（残留标记即报错中止）高
FR4排时：缺省按语速估算（每秒四字，可配置）；预留语音合成回写接口高
FR5结构线：章/节树，区间由子节点推导，进度条按章分段高
FR6重点线：句首标记的句子为核心句，播放时加粗、轨道出刻度高
FR7概念线：卡片标记生成弹卡，挂前面最近的分句，随讲弹出高
FR8画面线：每节一页幻灯片（标题＋要点），随讲切换高
FR9播放工作台：上/中/下三区布局，单一时钟，各线独立开关高
FR10声音线：逐句语音合成，句时长回写锚点（二期）中
FR11图谱线：主题图谱＋分句匹配，讲到点亮（三期）低
FR12意图线：纯人工标注界面，作为其他线的校订依据（三期）低
FR13静态退化：打印为文档时各线退化为加粗、页边卡、目录（三期）低

四、标记语法规范（讲稿 DSL）

讲稿为中文 Markdown。结构标记与标注标记如下，解析器对无法解析的标记必须报错中止，不得带病生成。

标记位置效果
# 标题行首章（大结构一级）
## 标题行首节（大结构二级），必须挂在章下，否则报错
【重点】句首重点线：该句为核心句（加粗＋轨道刻度）
【概念卡|标题|内容】任意概念线：弹出概念卡
【问答卡|问题|答案】任意概念线：弹出问答卡
【示例卡|标题|内容】任意概念线：弹出示例卡
【提醒卡|标题|内容】任意概念线：弹出提醒卡

挂载规则

  • 卡片挂给它前面最近的分句（可跨行）；若位于段首且该节尚无分句，挂给节内第一个分句；之后仍无分句可挂则报错；
  • 分句切分：以句末标点（句号、叹号、问号、分号）为界，保留标点；
  • 【重点】可与卡片标记同句共存；
  • 正文不得出现在任何章标题之前；节不得出现在章之前；违反即报错。

五、线协议（核心抽象）

任何线登记六要素后方可使用：

要素说明
编号与名称如 L2 重点线
锚点粒度章、节、分句、字四选一，向下兼容
呈现方式区间高亮、文字加粗、弹卡、点亮图谱节点等
生成方式自动 / 模型候选加人工校订 / 纯人工
默认开关工作台初始是否显示
依赖声明跨线依赖必须显式，禁止隐式依赖
编号名称粒度呈现生成
L1结构线章/节进度条分段＋大纲高亮自动
L2重点线分句加粗＋轨道刻度标记（可扩为模型候选）
L3概念线分句弹卡＋轨道刻度标记（可扩为模型候选）
L4画面线节幻灯片切换自动
L5声音线分句→字语音播放自动（二期）
L6图谱线分句点亮图谱节点匹配＋人校订（三期）
L7意图线分句作者侧批注纯人工（三期）
硬规则：线之间平权，可整体增删；每线产物独立落盘为一个文件；删任何线，母线与其余线不受影响；播放端每线一个开关。

六、数据结构规范（落盘契约）

6.1 母线锚点 anchors.json（解析段产物）

{
  "title": "分数的第一课",
  "total": 74.5,            // 总时长（秒）
  "rate": 4.0,              // 语速（字/秒）
  "chapters": [
    {
      "title": "分数的第一课",
      "t": 0.0, "dur": 47.5,            // 区间由子节点推导，不手工填
      "sections": [
        {
          "title": "从分蛋糕说起",
          "t": 0.0, "dur": 28.5,
          "utterances": [                // 分句 = 小结构锚点线
            { "id": "u0", "t": 0.0, "dur": 2.75,
              "text": "今天我们先从一个生日会讲起。",
              "core": false,             // 重点线标记
              "cards": [                 // 概念线标记（解析段暂存于此）
                { "kind": "warn", "title": "公平的含义",
                  "body": "公平不是随便掰一块……" }
              ]
            }
          ]
        }
      ]
    }
  ]
}

6.2 概念线 concept.json（加工段产物，独立落盘）

[
  { "kind": "concept", "title": "平均分",
    "body": "每一份的数量都相等，才叫平均分。……",
    "anchor": "u3",            // 挂接的分句
    "t": 18.2,                 // 弹出时刻 = 锚点分句开始时刻
    "dur": 8.6,                // 弹出窗 = max(3, 锚点时长 + min(4, 正文字数/20))
    "section": "从分蛋糕说起" }
]

6.3 画面线 slides.json（加工段产物）

[
  { "t": 0.0,                          // 本页起始时刻（=对应节的 t）
    "title": "从分蛋糕说起",
    "chapter": "分数的第一课",
    "bullets": ["第一分句原文", "第二分句原文", "第三分句原文"] }
]

6.4 时间推导规则

  • 分句时长 = max(1.2, 字数 ÷ 语速)；分句时间依序累加；
  • 节区间 = 首分句开始 → 末分句结束；章区间同理（推导，不手工维护）；
  • 卡片不占讲稿时长，是叠加层；
  • 接入语音合成后：分句时长 = 合成音频实际时长，回写同结构。

七、处理流水线规范（五段）

段输入输出（落盘）失败策略
① 源段主题思路 + 冻结讲稿复制入工作区缺文件即中止
② 解析段讲稿anchors.json标记残留/结构违规即中止
③ 加工段anchors.jsonconcept.json、slides.json（各线并行，各一文件）单线失败只重跑该线
④ 介质段母线＋各线文件播放工作台.html（单文件）失败即中止
⑤ 确认段全部产物台面页（产物链接＋验收勾选清单）人勾选后闭环
流向单向不回头：确认段发现问题 → 回解析段重走全流程，禁止在介质段就地打补丁。每段只读上一段产物文件，段间无隐式依赖。

讲稿生成（FR1/FR2）

  • 输入：主题、对象、思路（越具体质量越高）；
  • 生成：大模型按思路起草，章用 #、节用 ##，按思路把【重点】【概念卡】标记写进初稿；
  • 确认：台面逐节展示，人可改文字、增删标记；确认即冻结，冻结版进入源段。

八、播放工作台 UI 规格（FR9）

布局（自上而下）

区内容要点
顶栏标题、播放/暂停、时间显示、倍速（0.75/1/1.25/1.5）时间轴按章分段，段内填充进度，段标签随章名，点段跳转
上区（约四成高）幻灯片画面：标题＋要点列表随节切换（找到最后一个 t ≤ 当前时刻的页），白底卡片式，居中
中区（约四成高，滚动）讲稿分句：当前句蓝底高亮、已讲淡显、核心句加粗；卡片内嵌于锚点句下方点击任意句/卡跳转；当前句自动滚入视野；卡片未到时间淡显、到达时描边高亮
下区（固定）多线轨道：每线一行＝名称＋开关＋时刻刻度条＋播放指针点刻度跳转；开关关闭该线刻度隐藏且呈现淡出；指针全轨同步

联动规则（单一时钟）

  • 全页只有一个播放时刻变量；每条线是订阅者：拿到时刻，查自己的数据，决定亮什么；
  • 线之间互不调用、互不知道彼此存在；
  • 卡片弹出窗：t ≤ 时刻 < t+dur 时高亮。

呈现底线

  • 单文件网页：无外部脚本、无网络依赖、双击可开；
  • 最小字号 16px；全篇中文；
  • 打印为静态文档时各线退化：重点→加粗、概念→页边卡、结构→目录（三期实现）。

九、非功能需求

  • 离线可用：除讲稿生成与语音合成需联网外，解析、加工、装配、播放全部本地完成；
  • 可审计：每段产物落盘，任何一步可人工检查、可回滚；
  • 成本可控：模型调用按任务分派，逐句处理按需付费；候选一律人确认后入库；
  • 可扩展：新线 = 注册六要素 + 落盘文件 + 工作台开关，三步接入，不动母线逻辑；
  • 留痕：运行日志记录每次各段成败；修订须写理由。

十、验收测试清单

  1. 给定含全部标记类型的讲稿，解析后无残留标记符号；故意写错标记（缺分隔符），解析报错并指出位置；
  2. 节标题无章标题时，解析报错；正文先于标题时，解析报错；
  3. 改一个分句的文字，重跑后其所在节/章区间自动变化，无需手工改时间；
  4. 删除 concept.json 后重装配，工作台正常播放，仅概念线为空——验证线可独立增删；
  5. 工作台播放：幻灯片切换发生在节边界；核心句加粗与刻度同步点亮；卡片在锚点句弹出；
  6. 关闭概念线开关：卡片与轨道隐藏，重点线不受影响；
  7. 总时长与逐句时长之和一致；点任意刻度/句子/卡片段落跳转准确；
  8. 单文件检查：断网打开工作台，全部功能可用。
